# 簡介

頂端列本來就標出螢幕的上緣。Brow 放在正中間，貼著邊框，高度只跟那條列一樣。靜止時它是一個凹槽。滑鼠移上去或點一下，會展開成一座島。指標離開、在外面點一下，或是別的視窗取得焦點，它就收回去。

用 GJS/Clutter 寫成擴充功能，所以畫在 shell 上，而不是另外一扇視窗。

介面與功能參考 [Ripple](https://github.com/TopMyster/Ripple)。

UUID：`brow@jettakarn`。

# 功能

- 凹槽高度與 GNOME 頂端列相同。滑過會偷看一眼，點一下展開島。
- 總覽：時鐘、日期、天氣、電量。
- 搜尋。輸入網址或關鍵字後按 Enter，預設瀏覽器開啟，島接著關閉並清空。
- 捲動或滑動會循環分頁。有聲音在播時順序是總覽、音樂、搜尋、快捷、設定。沒在播就略過音樂。
- 覆蓋層不會疊在一起。指紋驗證會從音量條拿走島，音量條會從電池橫幅拿走島。被打斷的計時橫幅，時間還沒走完會再回來。驗證會清掉計時中的那些。

### 音樂

只有正在播放時才看得到音樂頁。上面有專輯封面、曲名、演出者、可拖曳的進度條，以及上一首、播放／暫停、下一首。輸出按鈕會打開音效設定。點專輯封面進入較高的播放器，再點一次回到原頁。

播放時，收起的島左邊是封面，右邊是從封面取色的頻譜。

![Music](previews/music.gif)

### 音量

系統輸出音量改變時出現音量條。拖曳軌道可調整大小。大約停留兩秒半。

![Volume](previews/volume.gif)

### 電池

充電與低電量橫幅。各自停留約三秒，然後島縮回去。

![Charging](previews/charging.gif)

### 快捷

圓形圖示排成蜂巢。靠近中心的較大。拖曳可平移，放開後還會滑一段。點一下開啟該應用程式或網站，並關閉島。關閉島或離開這一頁，格子回到正中間。

每一點是應用程式或網站，在擴充功能設定裡選。網站用該站的圖示。預設是二十個常用網站。

### 指紋

實驗功能。fprintd 開始驗證時，島變成圓角方形。圓環翻轉，比對成功時由左至右畫出勾。失敗則搖一下。改輸密碼就回到凹槽。

指紋島只在使用者工作階段裡運作，不包含 GDM 登入畫面。

![Fingerprint](previews/fingerprint.gif)

# 需求

- GNOME Shell 45 或更新版本
- [`playerctl`](https://github.com/altdesktop/playerctl)，用來讀取媒體資訊與控制播放
- 需要網路才能取得天氣（IP 定位與 [Open-Meteo](https://open-meteo.com/)）和網站圖示
- 選用：`fprintd`（或相容的 `open-fprintd`）以及已登錄的指紋，指紋島才會出現

# 安裝

```sh
git clone https://github.com/jettakarn/brow.git
cd brow
mkdir -p ~/.local/share/gnome-shell/extensions
ln -sfn "$(pwd)" ~/.local/share/gnome-shell/extensions/brow@jettakarn
glib-compile-schemas ~/.local/share/gnome-shell/extensions/brow@jettakarn/schemas
gnome-extensions enable brow@jettakarn
```

在 Wayland 上，先登出再登入一次，shell 才看得到新擴充功能。之後停用再啟用 Brow，就能載入程式變更。

# 用法

| 動作 | 結果 |
|--------|--------|
| 滑鼠移上去 | 偷看時鐘與電量；播放音樂時改看封面與頻譜 |
| 點一下 | 展開或關閉島。正在播放時，展開後停在音樂頁 |
| 展開時捲動或滑動 | 循環分頁。只有正在播放時，循環裡才有音樂頁 |
| 搜尋後按 Enter | 用預設瀏覽器開啟網址，或進行 Google 搜尋。島關閉並清空 |
| 接上電源 | 綠色充電橫幅，約 3 秒 |
| 放電中，電量降到低電量門檻或以下 | 紅色低電量橫幅，約 3 秒，每次下降只出現一次 |
| 音量加大、減小或靜音 | 音量條約 2.5 秒。拖曳軌道可調整大小 |
| 指紋驗證 | 方形掃描，成功時由左至右畫出勾，失敗則搖一下 |
| 音樂頁的專輯封面 | 打開或關閉較高的播放器。播放器開著時，在島外點一下會關閉島。指標移開不會 |
| 音樂頁的輸出圖示或 Sound | 打開「設定」的「音效」 |
| 音樂頁的播放控制 | 透過 `playerctl` 上一首、播放／暫停或下一首 |
| 快捷頁拖曳 | 平移蜂巢。放開後滑行，拉到邊緣會彈回 |
| 快捷頁點一下 | 開啟該應用程式或網站，然後關閉島 |

# 設定

顯示、音量、電池與指紋在島內的設定分頁。

- **溫度** 用攝氏或華氏。預設是攝氏。
- **時鐘** 用 24 小時或 12 小時。
- **音量** 顯示或隱藏音量條。
- **電池** 顯示或隱藏充電與低電量橫幅。
- **低電量** 是 15%、20% 或 25%。預設 20%。放電中降到這個門檻時出現一次，充到門檻以上後會重設。
- **指紋** 開啟或關閉實驗用的指紋島。

蜂巢在偏好設定頁。打開 **擴充功能**，選擇 **Brow**，再進 **Honeycomb**。可以新增、刪除、調整順序。每一點是應用程式或網站。
